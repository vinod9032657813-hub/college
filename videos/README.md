# Pet Videos for Shorts Section

## Instructions

Place your dog and cat videos in this folder with the following names:

### Dog Videos (3 videos needed):
- `dog1.mp4` - Dog Training/Playing
- `dog2.mp4` - Puppy Care
- `dog3.mp4` - Dog Exercise

### Cat Videos (3 videos needed):
- `cat1.mp4` - Cat Grooming
- `cat2.mp4` - Cat Playing
- `cat3.mp4` - Cat Tricks

## Video Requirements:
- Format: MP4
- Recommended: Vertical format (9:16 ratio) for shorts-style display
- File size: Keep under 10MB for fast loading
- Duration: 30-60 seconds recommended

## Where to Find Pet Videos:
1. **Pexels** - https://www.pexels.com/search/videos/dog/ (Free)
2. **Pixabay** - https://pixabay.com/videos/search/cat/ (Free)
3. **Your own pet videos** - Record your own!

## Current Status:
The videos will use fallback sample videos until you add your own pet videos to this folder.

Once you add the videos, refresh your browser to see them!
